Compiled context for coding agents

Send the paragraphs that matter. Skip the other 1,088.

mic compiles your repository once. For every question it links the few functions, definitions, callers and tests that answer it, and your agent reads those instead of exploring. On SWE-QA that is 7,300 tokens per answer instead of 77,900.


          
        

      

      
Works with Claude Code, Codex, ZCode and OpenCode, or with no agent at all. Python 3.10+, no dependencies.

A compiler, then a linker

      
The expensive understanding happens once, when a strong model compiles the repository. Every question after
        that is a cheap lookup and a link step.

    

    

      

        
1 · Compile, once

        
A strong model writes an agent-facing card for every file: what each function does, its literal defaults and
          error messages, its traps, and how people describe it without knowing its name. Citations are checked against a parsed symbol table.


Schematic._verify_configuration_completed

_got_registered_once is True
aka: "check preventing configuration
      changes once first enrollment
      has happened"

      

      

        
2 · Link, per question

        
Seed paragraphs come from the compiled notes and aliases. A symbol-level link graph then pulls in what they
          reference and what calls them. No model call; about 30 ms. These are the real picks for the question above.


seed  Schematic._verify_configuration_completed
seed  App._verify_configuration_completed
seed  test_program_query_handling
  link  preparationmethod · skeleton.py
  link  Schematic.note_once_only
  link  App.enroll_plan

      

      

        
3 · Send only that

        
Seeds go in as live source read from disk, so they are never stale. Links go in as one line each with an exact
          span. The agent answers, or reads a cited span, instead of searching the repository.

One tool, every agent

      
mic install detects the agents you have and wires each one in, merging into its existing config.
        It compiles with whatever model access you already have: the claude or codex CLI, an Anthropic key, or any
        OpenAI-compatible API such as GLM, DeepSeek, OpenRouter or Ollama.

    

    

      
Claude Code
hooks + MCP + commands
        
  • link pack on every prompt
  • large-file read guard
  • /mic:ask, /mic:compile

      
Codex
hooks + MCP
        
  • link pack on every prompt
  • codex mcp server mic

      
ZCode
hooks + MCP
        
  • loads the Claude plugin as is
  • MCP in ~/.zcode

      
OpenCode
MCP + command
        
  • MCP tools and a /mic command
  • AGENTS.md tells it to ask mic first

      
No agent
CLI
        
  • mic ask "…": one-call answer
  • mic pack "…": paste into any chat
